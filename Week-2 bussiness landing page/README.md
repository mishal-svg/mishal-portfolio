# Amir Solar & Tech - Business Landing Page

## 📌 Project Overview

A responsive business landing page developed for **Amir Solar & Tech**, a solar energy and technology solutions company. The website is designed with a modern UI, clean layout, and responsive design to provide a professional online presence.

## 🚀 Features

* Responsive design for Desktop, Tablet, and Mobile devices
* Modern navigation bar with smooth scrolling
* Hero section with call-to-action buttons
* Services showcase section
* About company section
* Why Choose Us section
* Working process section
* Pricing section
* Customer testimonials
* FAQ section with JavaScript interaction
* Contact section with clickable phone and WhatsApp links
* Professional footer design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
